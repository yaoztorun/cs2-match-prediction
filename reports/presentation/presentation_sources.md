Every figure, table and metric in `reports/presentation/cs2_match_prediction_presentation.pptx`,
traced to its frozen source. Presentation-only re-plots live in
`reports/presentation/figures/` and are generated by
`reports/presentation/build_presentation_figures.py` (numbers transcribed from the
reports below — nothing recomputed). The deck itself is built by
`reports/presentation/build_presentation.py`; speaker notes are exported to
`reports/presentation/presentation_speaker_notes.md` by `reports/presentation/export_speaker_notes.py`.

(e.g. Cologne accuracy 0.6415 → 0.642 / "≈0.64").

## Deliberately excluded / guarded claims
- No claim that Log Loss/Brier improvements are "calibration" (no calibration was fitted anywhere; Phase 7/8E report raw probabilities).
- Falcons' 8.93% is compared to the uniform 32-team reference (3.125%), never to a coin flip.
- Cologne results are described as an external demonstration on one event, never as statistically proven improvement (per `phase8e` §R).
- The tournament simulator is described as sampling winner ~ Bernoulli(p), never as advancing p>0.5 favorites (the deterministic favorite path is shown only as a contrast, per `phase8d` §M / `phase8e` §O).
- RF V2 = pre-veto application model; XGB V3 = known-map model; they are never presented as competing on the same task.
